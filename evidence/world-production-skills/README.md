# World production skill validation

Scope: repository development skills derived from Engineering and Vanguard,
2026-09-07. The implementation adds `starbase2-3d-assets` and
`starbase2-world-qa`, focused references and a review template, and routes them
from the existing world skill/catalog. Runtime game and agent behavior are not
changed by this skill-authoring task.

Validation results are in `validation.log`. Check names/frontmatter and unfinished
scaffolds with the skill-creator validator, parse UI metadata, resolve the two
Claude symlinks, and run the repository documentation link/status checks.

Scenario self-review uses the cases in `docs/skills-review.md`: existing assets
are inspected before generation; total budget includes prior/pending charges;
uncertain submissions stop redispatch; static props do not need rigs; helmet
repairs are model-specific; lightweight HUD/docs changes avoid asset workflows;
headless/region tests do not substitute for visual acceptance; qualification
binds the exact source; runtime capability changes still route to agent.

This is static validation plus author self-review, not an independent agent trial
or proof that either application has refreshed its skill catalog. The next
structure/character task is the concrete field test. No credits, external
publication or runtime memory updates were used for this task.
