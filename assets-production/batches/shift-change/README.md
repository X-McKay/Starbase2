# Shift Change

Status: proposed

Implementation branch: `codex/shift-change`. Al owns final visual/play-feel
acceptance. The intended slice is an inhabited Habitat–Commons–Command
neighborhood, using the [generated target](concepts/art-target-v1.md) and the
[research findings](../../../docs/astra-world-research.md). The target is not a
runtime screenshot. The research informed construction and independent native
criticism; no external skill package was installed.

## Implemented

- Seven reserved home locations across Habitat and Commons. Crew choose an
  available anchor, linger, move to another, leave for authoritative work and
  return when no active assignment remains. Navigation failures and stale state
  stay explicit. Travel never gates backend completion.
- Three rig-specific Blender animation libraries: sit down, seated and stand up.
  Original Meshy characters and their normal locomotion remain the selected
  geometry. Per-instance material corrections, grounded scale and actual native
  front/side skin inspection resolve the reproduced integration failures.
- A coherent domestic kit: timber, woven rug, textiles, plants, pendants,
  journals, cups and functional seats. Habitat's generated sofa now anchors the
  central lounge; the Commons carries matching details.
- A compact native crew strip, contextual inspector and explicit watch action.
  L visits Habitat; normal live startup enters it. Expanded evidence workspaces
  retain their space. Floating labels show concise status; full records remain
  available in the inspector. Camera changes never dispatch work or teleport crew.

Production assets: [domestic kit](../../kits/aster-domestic/README.md) and
[social clips](../../characters/shift-social/README.md). The concept uses built-in
image generation; the new geometry/animation uses Blender5.2.1 and the actual
Godot4.7.2 Compatibility renderer. Existing Meshy work is reused. **Zero new
Meshy credits** were spent; previous allowances were not reset or combined.
