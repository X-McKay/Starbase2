Starbase2 service

This endpoint serves the Starbase2 API. Open the Starbase2 Godot application for the world, observations, evidence, and operator controls.

In Godot, open Connection and enter the local Core address. For a remote installation, establish its approved private port forward first, then use that local address. Check the installation identity before starting work.

The API remains available to the native application. This page also establishes its local operator session; it contains no dashboard controls.

If the application is unavailable, use the documented operator CLI or GitOps emergency stop for the installation.
